Xteink X3 · CrossPoint fork · v1.8.2-365

Install CrossPoint 365

The new Mono look with Geist type and filled icons, a Google Calendar sleep screen that updates itself, a Focus (pomodoro) timer, Year Progress and Reading Heatmap sleep screens, and home-screen widgets. Flashes over USB straight from this page — nothing to download or install. Your SD card (books, reading progress) is untouched.

1 · Plug the X3 into this PC with a USB data cable

Turn the X3 on. Windows 10/11 recognizes its USB port on its own (it appears as a “USB JTAG/serial debug unit” COM port). If it doesn’t show up, try another cable — many USB-A cables are charge-only.

2 · Use Chrome or Edge, then click Install

This browser can’t talk to USB devices. Open this page in Chrome or Microsoft Edge. Serial access needs an https page — reload over https.

A dialog lists the COM ports; pick the X3’s and confirm. The flash takes about a minute; the X3 reboots into the new firmware afterwards. When asked, do not erase the device — it isn’t needed.

3 · On the X3

  1. The fork switches to the new Mono theme on first boot — pick any theme back under Settings → Display → UI Theme (and UI Font for Geist/Ubuntu).
  2. Calendar on the sleep screen: Settings → Display → Sleep Screen → Calendar, then open the Calendar row below it and paste your Google Calendar “secret address in iCal format” (Google Calendar → Settings → your calendar → Integrate). Pick the update cadence — every 10 min by default while asleep.
  3. Focus timer: the new Focus tab on the home screen. Left/Right pick the focus length, Up/Down the break; it keeps running while you read (see the status bar).
  4. Settings → Display → Home Widgets → choose the four slots; set a city for weather and tap Refresh weather now.
  5. Clock features need the time once: run Sync clock now over Wi-Fi. The X3 keeps time in its RTC afterwards.
Other ways to install

No cable: copy firmware.bin to the root of the X3’s SD card, then Settings → System → SD Card Firmware Update (if your current CrossPoint has that entry).

Manual esptool: merged-full-image.bin is the whole flash as one file for offset 0x0: esptool --chip esp32c3 write-flash 0x0 merged-full-image.bin. A ready-made Windows package with esptool.exe is on the releases page.
